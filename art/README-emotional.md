# Команда C · Emotional Art & Cinematic Lighting

Ветка: `feat/aki-art-emotions-11-16` → PR в `main`. Редактируются **только сцены 11–16**: `decide`, `wind`, `offer`, `tired`, `bearcomes`, `talk`.

## Архитектура / границы владения

В исходном приложении все 22 определения сцен, рендерер Canvas и точка запуска находятся в `index.html`. Чтобы не конфликтовать с командами A/B/D, **`index.html` не редактировался**. Арт-слой находится в `art/emotional-art.js`, подключается **после** основного директорского скрипта и регистрирует обёртки только для шести scene definitions.

Для интеграции в финальную сборку координатор может подключить один классический скрипт после исходного `<script>`:

```html
<script src="art/emotional-art.js"></script>
```

Этот шаг **ещё не включён в основной `index.html`**, так как он принадлежит интегратору. Вместо изменения исходника есть отдельный предпросмотр:

```sh
node tools/build-emotional-preview.mjs
# открой emotional-preview.html#s16t12f
```

Автоматический предпросмотр внедряет загрузчик в копию HTML и сохраняет оригинальную ссылочную структуру `voice/`. Все прочие сцены без изменений. Взаимодействие с командой B: позы корректируются поверх текущего базового `creature`, сами функции `drawFox`, `drawBear`, `drawHare`, их общие цвета, тело, анимации и спрайты не заменяются. Локальный временный перехват вызовов `creature` ограничен синхронной отрисовкой принадлежащей нам сцены и **всегда восстанавливается** через `finally` (в том числе при исключении).

## Художественные решения

| Сцена | Мимика / эмоция | Свет / окружение |
| --- | --- | --- |
| `decide` | Внимательный взгляд, уверенность без напряжённого оскала | Тёплый фокус, мягкий янтарный свет |
| `wind` | Живые, различимые глаза даже при порывах ветра, терпеливое усилие | Приглушённые золотисто-оливковые оттенки, локальная трава/саса, повторяющая **имеющийся** gust |
| `offer` | Доброжелательная мордочка зайчика; отказ лисички не превращается в слишком жёсткий прищур | Мягкий свет вокруг обоих, без нарушения дистанции в композиции |
| `tired` | Усталые веки, мягкие щёки и опущенные уши без болезненных искажений | Тёплая вечерняя палитра вместо давящего мрака |
| `bearcomes` | Сочувствующий взгляд медвежонка; постепенно более открытая мимика лисички | Золотистые подсветки и спокойные тени |
| `talk` | Постепенное восстановление доверия; видимый мягкий изгиб рта | Парные тёплые световые пятна как композиционный акцент |

Параметры света хранятся в объекте `LIGHT`. Весь свет — радиальные и линейные Canvas-градиенты, без `filter: blur`, без изменения таймингов, без новых огромных буферов. Художественный слой в сцене ветра использует `windState(t).gust` и не меняет `LeafFall`, `WindStreaks`, `WIND_T`, анимацию крыши или камеру.

## Проверка

```sh
node --test tools/verify-playback.mjs tools/verify-emotional-art.mjs
node tools/capture-emotional.mjs
# открыть emotional-review.html
```

Команда захвата требует локально доступного Chrome/Chromium (или `CHROME_BIN=/path/to/chrome`). Она генерирует 12 полноразмерных кадров по шести сценам — `before` на исходном `index.html` и `after` в версии с арт-слоем. HTML-галерея показывает оба кадра и **увеличенные области эмоций**. Захват проводится на фиксированных `#sNtTf`, одинаковых для исходной и новой версий. Он не тестирует физику реального устройства и не заменяет ручную визуальную проверку.

Также добавлен GitHub Actions workflow `Emotional Art · Team C`. Он проверяет синтаксис, изоляцию, регрессию воспроизведения и публикует `aki-emotional-art-before-after` как **workflow artifact**. Перед интеграцией открыть галерею и проверить лицо лисички, ушки зайчика, взгляд медвежонка и контраст теней на слабом/мобильном устройстве.

## Ограничения интеграции

- Базовая палитра и рисунок персонажей остаются за командой B.
- Мы не меняем сюжет, текст, звуковые дорожки, переходы, длительность, координаты, состояния, базовые камеры или общую функцию отрисовки.
- `index.html` и сцены других команд не меняются; сборка для финальной публикации должна отдельно загрузить модуль.
- Сценарий захвата создаёт незакоммиченные артефакты только для визуальной QA.
