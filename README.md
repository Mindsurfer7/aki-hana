# Аки Хана · 秋花

Анимированная сказка-презентация о лисичке Аки Хана из осеннего леса Хоккайдо: 22 сцены, графика на Canvas 2D, звук — WebAudio. Без внешних JavaScript-зависимостей, всё в `index.html`.

**Запуск:** открыть `index.html` в браузере (Chrome / Safari / Firefox).

### Как отправлять сказку людям со звуком

**Если отправить только исходный `index.html`, голоса не будут работать:** MP3 находятся отдельно в `voice/00.mp3` — `voice/21.mp3`. Для пересылки одного файла соберите полноценный автономный HTML:

```bash
python3 tools/build-portable.py --output dist/aki-hana-full.html
```

Отправляйте получателям именно **`dist/aki-hana-full.html`**. В нём уже находятся все 22 звуковые дорожки, интернет для воспроизведения голосов не нужен. GitHub Actions также прикладывает собранный HTML к каждому успешному прогону как артефакт **`aki-hana-full-single-html`**. Если публикуете сказку через обычный веб-сайт, можно использовать `index.html`, но нужно обязательно разместить рядом папку `voice/` с MP3.

В мобильных браузерах звук запускается **после нажатия на кнопку старта** (требование iOS Safari, Chrome и встроенных браузеров). Теперь все каналы используют один разблокируемый WebAudio-контекст, в том числе озвучка; если браузер приостановил его, появится кнопка **«🔊 Включить звук»**. Не ожидайте звука до первого нажатия. Если файл открылся в предпросмотре мессенджера без поддержки скриптов/аудио, выберите «Открыть в браузере» и проверьте громкость медиа на телефоне.

## Управление

- **«Звук ⚙»** — панель громкости голосов, музыки и природы с сохранением настроек.

- **→, пробел, клик, кликер** — следующая сцена, **←** — предыдущая.
- **A** или кнопка **«Авто»** — автоматически переходить к следующей сцене через 0,65 секунды после окончания озвучки. На начальном экране есть **«Автопоказ ▶»**. На последней сцене показ останавливается. Если озвучка недоступна, используется длительность сцены; зависшее воспроизведение может задержать её не более чем на 12 дополнительных секунд.
- **B** или **♫** — отключить *только музыку*, оставив звуки природы и озвучку.
- **N** или **≋** — отдельно включить/выключить ветер, ручей, птиц и сверчков.
- **M** — отключить все фоновые звуки WebAudio (музыка и природа), но не озвучку.
- **V** — включить/выключить озвучку сказки, если соответствующие MP3 доступны в `voice/`.
- **T** — текст сказки, **F** — полный экран, **?** — справка.

На узких экранах остаются кнопки переключения музыки, природы, автопоказа и навигации. Выключение музыки отключает также её реверберацию и создание новых музыкальных нот.

## Работа на слабом устройстве

Приложение ограничивает отрисовку до **30 кадров/с** и автоматически снижает внутреннее разрешение по замерам времени кадра. При небольшом числе ядер или объёме памяти оно стартует на пониженном качестве. Во время перехода исходящая сцена рендерится в буфер один раз, вместо повторной отрисовки обоих миров каждый кадр. На низких уровнях качества дорогие полноэкранные размытия, bloom и зерно отключены; остаются масштабированные мягкие слои и виньетка.

Можно вручную выбрать режим через параметры URL:

- `?q=high` — максимальное качество; `?q=med` — среднее.
- `?q=low` — упрощённая постобработка; `?q=ultra` — ещё ниже разрешение для совсем слабых устройств.
- `?fps=60` — поднять потолок частоты до 60 fps (не рекомендовано для слабого железа).
- Выбранный через URL `q` фиксируется, автоматическое переключение качества в этом случае отключено.

**Отладка:** `index.html#s5t9f` — стоп-кадр на 9-й секунде 5-й сцены, `#x10p50` — середина перехода к 10-й сцене, `#perf` — прогон сцен с замерами времени кадра.

Для реальной проверки плавности нужно тестировать на целевых устройствах: загрузка CPU, нагрузка GPU и работа Canvas-фильтров заметно различаются между браузерами.

**Озвучка:** готовые записи в `voice/00.mp3` … `voice/21.mp3` воспроизводятся вместе со сценами. Для лисички выбран взрослый мультяшный женский голос «Мэвис голос» (`02f8eff6783c4fe59a849cc439f250e9`), для зайчика — мужской голос «Крош» (`3866bdb5e1e24cdb94599b70a7f07a35`). Эмоции передаются тегами S2 в тексте; описания рядом с ID — комментарии к выбору, не параметры API.

Перегенерация: `python3 tools/voice.py voice` (нужен `ffmpeg`). Только сцены с лисичкой и зайчиком: `python3 tools/voice.py voice 9 10 12 14 17 20` (нумерация с нуля). Модель — `s2.1-pro-free`. Ключ берётся из переменной `FISHAUDIO_API_KEY` или существующего локального `.env` проекта qonbaq, в браузер не передаётся. Новые реплики персонажей кэшируются с учётом голоса, текста и модели; прежние записи рассказчика и медвежонка переиспользуются.

Документация Fish Audio: [TTS](https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech), [эмоциональные теги](https://docs.fish.audio/developer-guide/core-features/emotions).

**Баланс звука:** кнопка «Звук ⚙» открывает отдельные ползунки голоса, музыки и природы (0–100%) и выключатели каналов. Изменения слышны сразу и сохраняются локально в браузере. Начальный баланс: голос 100%, музыка 35%, природа 30%. «Сбросить настройки» возвращает этот баланс. `M` переключает музыку и природу, `V` — голоса.

В автопоказе все сцены переходят дальше через 0,65 секунды после окончания озвучки. Если аудио недоступно, используется обычная длительность сцены.
