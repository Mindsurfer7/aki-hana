# Аки Хана · 秋花

Анимированная сказка-презентация о лисичке Аки Хана из осеннего леса Хоккайдо: 22 сцены, вся графика рисуется кодом на canvas, звук генерируется через WebAudio. Без зависимостей — один файл.

**Запуск:** открыть `index.html` в браузере (Chrome/Safari/Firefox).

**Управление:** → / пробел / клик / кликер — дальше, ← — назад, `T` — текст сказки, `M` — звук, `F` — полный экран, `A` — автопоказ.

**Отладка:** `index.html#s5t9f` — сцена 5 на 9-й секунде, стоп-кадр; `#perf` — прогон всех сцен с замером времени кадра.
