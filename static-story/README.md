# Аки Хана — статичная версия сказки

Две **готовые, независимые от анимационного движка** презентации на 22 сцены:

- [До редизайна](classic/index.html) — оригинальный Canvas-рендер без новых арт-модулей.
- [После редизайна](disney/index.html) — рендер с четырьмя подключёнными арт-модулями.
- [Выбрать версию](index.html).

Слайд — заранее созданный WebP (1600 × 900), а не Canvas, который рисуется при каждом кадре. Никаких анимаций, интервалов отрисовки, полноэкранных фильтров или автоматических переходов. Есть переключение кнопками, стрелками, списком сцен и необязательная озвучка оригинальных voice/NN.mp3. Все 44 изображения хранятся в Git и доступны офлайн, когда скачан весь репозиторий. При отдельном копировании папки static-story/ понадобится также voice/ для озвучки; листание без неё работает полностью.

Для обновления картинок после изменений основного фильма:

    npm install --no-save playwright
    npx playwright install chromium
    node scripts/export-static-story.mjs
    node scripts/check-static-story.mjs

Экспортёр поднимает кратковременный локальный HTTP-сервер, использует debug-режим исходного фильма #sNtTf, снимает **два настоящих кадра с одинаковым временем** на сцену и полностью отключает новые арт-модули только в своей временной classic-копии HTML. Оригинальный index.html не меняется. Папки frames/ и готовые index.html создаются экспортёром. Генерация автоматически выполняется в GitHub Actions для интеграционной ветки и коммитит полученные кадры в неё.

Время кадра для каждой сцены задаётся в scripts/export-static-story.mjs. Если нужен другой момент, поменяйте TIMES и запустите экспорт повторно.

Проверка scripts/check-static-story.mjs гарантирует, что обе папки содержат по 22 ненулевых WebP, манифесты и автономные HTML-просмотрщики, а картинки обеих версий получены из одинаковых timecode.
